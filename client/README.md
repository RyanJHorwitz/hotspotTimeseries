# Chronological Kernel Density Estimation to Identify Elephant Poaching Hotspots Across Africa

Using genetic information from elephant ivory samples, scientists in the Center for Environmental Forensic Science (CEFS) at the University of Washington are able to estimate the locations where elephants were poached in Africa (Wasser et al. 2004; Wasser et al. 2007).  These samples come from tusks that were intercepted along trade routes in “seizures” by local governments and law enforcement where the seizures take place.  After CEFS scientists receive a seizure’s samples – as a result of CEFS partnerships with local authorities – and its geneticists process them, CEFS bioinformaticians run processed samples through two computer programs: first SCAT and then VORONOI.  The output of these programs is a point pattern.  Specifically, the programs return a set of XY coordinates representing the best predicted geographic origins for all elephant samples in a seizure.  Alone, the point estimates of samples in a single seizure are informative, providing a snapshot of poacher geographic preference.  Together, however, point estimates of all seizures in CEFS’ database are even more powerful, providing decades-long insight into the way in which these preferences have shifted over time.  Indeed, CEFS has over 20 years of seizures in its database.

This interactive figure captures temporal changes in elephant poaching hotspots.  In particular, it displays the cumulative kernel density estimation (calculated from the VORONOI output point estimates) over time.  For each seizure, kernel density was calculated using the density.ppp function in the spatstat package in R.  Default bandwidth was set to 0.9 multiplied by the number of points in a pattern to the power of -0.2, multiplied the smaller of either (A) the standard distance or (B) the inverse of the natural log of 2 times the median distance from the mean center (Silverman 1986).  A quartic smoothing kernel was used and Jones-Diggle edge correction applied.  The output pixel size was set to 20 square kilometers for processing speed.  Once individual kernel densities were determined for each seizure, they were sorted chronologically according to seizure date, from oldest to newest.  The cumulative kernel density was then found by looping through each seizure and adding the most recent kernel density to the kernel densities of the older seizures.  Focal statistics with a window of 3 meters was used to smooth the summed outputs.  Finally, plots at each seizure timestep were visualized with color scale classed by Fisher-Jenks natural breaks.  Note that the color scale was kept constant across all plots, such that the minimum and maximum values on the scale are the minimum and maximum values across all timesteps, not just for the timestep being displayed.

The resulting plots were produced for seizures of both savannah and forest elephants, and compiled into an interactive figure.  The figure was built using HTML, CSS, and JavaScript (React front-end, Express back-end).  It is responsive, coded for all screen sizes.  It is generally accessible, having mouse-based, keyboard-based, and tab-based navigation, NVDA screen reader compatibility, and color-blind safe colors.  Further, it simplifies complex data and trends for non-scientists and maintains visual appeal without sacrificing data accuracy or reliability.  A JavaScript-free version of this figure does not exist.  For more information, please contact cefs@uw.edu.
